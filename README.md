# فنّ الدار

Build a premium, modern Saudi wall-art e-commerce storefront.

CRITICAL REQUIREMENTS

The entire website must be Arabic only. No English text anywhere in the UI.

Full RTL layout across all pages and components.

Use elegant Arabic typography.

Currency: Saudi Riyal (ر.س).

Create a luxurious visual identity using warm ivory, beige, charcoal, and subtle gold accents.

Make it feel like a high-end Saudi art brand, not a generic template.

Design inspiration
Take inspiration from LOHA Saudi and Khallab for product presentation, collections, and shopping experience. Do not copy their designs.

Pages and sections

Homepage with a premium hero section, featured collections, best sellers, new arrivals, and promotional banners.

Shop page with category filters, sorting, and product cards.

Product details page with large artwork images, size options, price, and add-to-cart button.

Shopping cart and checkout UI.

Wishlist page.

About us and contact pages.

Use my uploaded artwork images as the actual product images. Do not replace them with random images.

Scope limitation
Build FRONTEND UI ONLY. Do not implement database, authentication, payment gateways, backend, or admin functionality yet. Keep the code ready for later backend integration.
Do not rebuild or change the project structure unnecessarily.    Also create a separate Arabic RTL admin dashboard frontend matching the attached dashboard reference image. Include dashboard overview, orders, products, categories, customers, coupons, reports, and settings. UI only, no backend functionality.
